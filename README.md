# Sistema de Reservas: Club Social "Los Álamos"

Sistema para administrar la reserva de instalaciones y servicios del club (quinchos, salones, canchas, parrillas, etc.) por parte de sus socios.

## Stack

- **Lenguaje:** Java
- **IDE:** Eclipse
